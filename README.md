# SIGNAL

**18+ adult project.** One video at a time. No catalog. No related. No deciding.

Tube sites are built for hunting: thumbnail walls, recommended rows, infinite choice. SIGNAL is the opposite. It draws a random clip from public webmaster APIs (Eporner, Pornhub, RedGifs) and plays it. The only action is Next.

## Use

- Confirm you are 18 or older
- Watch whatever comes on
- **Next** (or right arrow / `N`) skips
- Optional tuner biases length and vibe. It never opens a list

## Pages

| Path | What |
| --- | --- |

## Notes

Videos are third-party embeds. Nothing is uploaded or stored here. Age confirmation and recent clip IDs stay in your browser (`localStorage`).

Built as a TanStack Start + React app.
